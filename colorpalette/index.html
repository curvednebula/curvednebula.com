Create a UI Color Palette from One Color ​

Build a UI color palette from a single base color. Preview it in light and dark interfaces, then export ready-to-use color ramps and named design tokens.

Supported features ​

  • Base color controls - pick a color on the wheel, adjust hue, saturation, and value, or enter a hex value.
  • Nine color harmonies - choose monochromatic, complementary, split complementary, double split, triadic, tetradic, square, analogous, or accented analogous palettes.
  • RYB and RGB wheels - switch between traditional artists' color relationships and the digital hue circle used by screens.
  • Tints and shades - generate five levels for each hue, from a pale tint through the base color to a deep shade.
  • Light and dark previews - see the palette in working interfaces with plain pages and tinted cards, or tinted pages and plain cards.
  • Contrast checks - view your base color's contrast against white and black text; verify the specific pairs you use against your accessibility requirements.
  • Design tokens - export named colors for surfaces, borders, headings, body text, buttons, accents, and chart or status colors.
  • CSS export - copy custom properties for both interface variants, with dark values in a media query that follows the system color scheme.
  • Palette export - copy individual hex values, a complete hex list, or JSON, or save the palette as a PNG image.
  • Local processing - generate and export palettes directly in your browser.
